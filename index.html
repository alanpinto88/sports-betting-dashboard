Build status and integrity rules

Supported sport filters: NFL, CFB, MLB, NBA, WNBA, Soccer, Tennis, UFC, MMA, PGA, NASCAR, F1, NHL and CBB. This standalone dashboard does not alter the existing NHL database, predictions, or frozen forecasts.

Current features: responsive layout, manual quote evaluation, +EV filter, persistent local bet ledger, manual settlement, structured optional market metadata, non-binding standard settlement preview and NHL final-score lookup, P/L, ROI and calendar. Entries stay in this browser's local storage; they do not sync across devices.

Not yet implemented: live sportsbook ingestion, historical 24-hour snapshots, provider-backed sharp/public signals, sport-specific predictive models, account login, server database and official-score settlement. Those features require verified data sources and additional engineering.

Model integrity: freeze predictions before event start; store original odds, model version, source and capture timestamp; do not backfill missing prices or present simulated figures as live data.
